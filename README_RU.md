## 🌟 Топ-Проекты

### 🛡️ [Bot-Amnezia-WG](https://github.com/StigMary/Bot-Amnezia-WG)
Многофункциональный Telegram-бот для безопасного управления VPN-сервером на базе AmneziaVPN / WireGuard. Включает кабинет клиента, админ-панель, систему тикетов (Helpdesk), биллинг и поддержку нескольких устройств на пользователя.

### 📷 [PhotoReport-Pythonista](https://github.com/StigMary/PhotoReport-Pythonista)
Нативное мобильное iOS-приложение для создания структурированных фотоотчетов. Написано полностью на Pythonista 3. Поддерживает автоматическое добавление водяных знаков с датой/временем, управление объектами и экспорт отчетов в ZIP в один клик.
